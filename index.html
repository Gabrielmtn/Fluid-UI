Hotkeys

Recording & Transport

  • Space — Play / Pause Layer
  • Shift+Space — Play All / Pause All
  • F9 — Record (3-2-1 countdown)
  • Shift+F9 — Record Immediately
  • Esc — Stop All (recording + playback)
  • ↑ / ↓ — Cycle Layers
  • Delete — Clear Active Layer
  • Ctrl+Shift+N — New Layer

Undo/Redo

  • Ctrl+Z — Undo
  • Ctrl+Y / Ctrl+Shift+Z — Redo

Canvas/Display

  • T — Toggle Trail
  • C — Toggle Cursor
  • H — Toggle Border & Handles
  • L — Lock/Unlock Borders
  • S — Focus Mode

Export & Mutation

  • E — Quick Export (Video)
  • M — Mutate Settings

Brush

  • [ / ] — Brush Size − / +
  • Shift+[ / Shift+] — Coarse − / +
  • Scroll — Brush Size − / +
  • Shift+Scroll — Rotate Brush (angle)

Colors & Palettes

  • R — Toggle Random Colors
  • A — Toggle Step Through Palette
  • N — Next Color
  • Shift+S — Save Color
  • Shift+X — Clear Colors
  • Ctrl+← / Ctrl+→ — Prev/Next Palette

Resolution

  • Alt+↑ / Alt+↓ — Visual Quality + / −
  • Alt+Shift+↑ / Alt+Shift+↓ — Physics + / −

Physics

  • Ctrl+Scroll — Density − / +
  • Ctrl+Shift+Scroll — Motion Isolation (Velocity Influence) − / +

Multiplier

  • 1..8 — Set Multiplier to 1x..8x
  • Numpad 1..8 — Set Multiplier to 1x..8x

Help

  • F1 or ? — Toggle Hotkeys
  • Esc — Close / Stop All
