COMPONENT LEGEND

COLOR BAR:
  [●] = Color swatch (clickable)
  ▣   = Palette color chip
  🎲  = Random color
  💾  = Save color
  🗑️  = Clear colors

MIXER PANEL:
  ║   = Vertical fader (drag up/down)
  ▓   = Fader position indicator
  ◉   = Radial knob (drag to rotate)
  ╱ ╲ = Knob arc indicator
  ╲ ╱

LAYERS PANEL:
  👁️  = Visibility toggle
  [thumb] = Layer thumbnail preview
  [+] = Add layer
  [−] = Delete layer

═══════════════════════════════════════════════════════════════════════════════

INTERACTION PATTERNS

COLOR SELECTION:
1. Click primary swatch → Opens color picker
2. Click palette chip → Selects that color
3. Click 🎲 → Random color
4. Click 💾 → Save current color to palette

MIXER CONTROLS:
1. Faders: Click and drag vertically
2. Knobs: Click and drag in circular motion
3. Values update in real-time below control
4. All changes sync with simulation immediately

LAYER MANAGEMENT:
1. Click layer item → Select/activate
2. Click 👁️ → Toggle visibility
3. Click [+] → Add new layer
4. Click [−] → Delete selected layer

SETTINGS:
1. Click ⚙️ icon → Open/close panel
2. Adjust settings → Changes apply immediately
3. Click ✕ or outside → Close panel
4. All settings sync with main controls

WORKFLOW EXAMPLES

QUICK COLOR CHANGE:
1. Click palette chip in color bar
2. Start painting immediately
3. Colors update in real-time

PARAMETER ADJUSTMENT:
1. Drag fader in mixer panel
2. Watch value update below
3. See effect on canvas immediately

LAYER ORGANIZATION:
1. Create new layer with [+]
2. Toggle visibility with 👁️
3. Select layer to make active
4. All edits apply to active layer

PRESET APPLICATION:
1. Click ⚙️ to open settings
2. Click preset button
3. All parameters update
4. Close settings or continue adjusting
